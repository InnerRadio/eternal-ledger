================================================================================
LOCKED SAFETY PRINCIPLES
================================================================================

The canonicalizer does not perform:

- cross-source entity resolution
- name-based Organization matching
- website-based Organization matching
- fuzzy matching
- automatic Organization merging
- OrganizationMember creation
- ownership inference
- employment inference
- volunteering inference
- Partner inference
- eligibility determination
- commerce determination
- publication
- Directory mutation
- frontend mutation
- API exposure

Same-source idempotency is anchored by canonicalization provenance.


================================================================================
TRANSACTION PRINCIPLE
================================================================================

The canonicalizer does not call db.commit().

The caller owns the transaction.

This permits target creation + provenance creation + verification to remain one
logical transaction before commit.
