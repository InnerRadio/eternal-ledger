# Eternal Ledger Architecture

## Overview

Eternal Ledger is designed as a lightweight XRPL-native digital continuity infrastructure framework.

The initial deployment layer is:

# PurPaws.ca

A companion memorial archive platform designed to onboard public users into emotionally meaningful XRPL NFT utility.
